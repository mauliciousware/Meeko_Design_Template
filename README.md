# Meeko portfolio

A standalone Next.js website with its images, icons, and fonts in `public/sites/meeko/`.

Requires Node.js 24 or newer.

```sh
npm install
npm run dev
```

Open the local URL printed by Next.js.

For a production build:

```sh
npm run build
npm start
```

Run `npm run check` for lint, TypeScript, and production-build checks.

## Vercel

Deploy this folder's current files with the Next.js framework preset and the repository root as the project root. The build command is `npm run build`; leave the output directory at its Next.js default. No environment variables are required.

For Git-based deployments, commit and push the contents of this folder to the repository connected to Vercel, then redeploy that commit. Deploying the original template repository will not include this local website.
